Інвентаризація ПЗ через n8n + Claude — встановлення

Система читає вивід winget list, зводить пакети до продуктів і розкладає їх по категоріях. Класифікує Claude, але тільки те, чого ще немає в довіднику: повторний прогін того самого файлу коштує 0 запитів до AI.



Разом із цією інструкцією ви отримали два файли:



Software\_inventory\_catalog\_Claude.json — основний workflow

Software\_inventory\_setup\_run\_once.json — установник таблиць

API-ключів у них немає: n8n ніколи не вивантажує секрети. Свій ключ ви додасте на кроці 2.



Що потрібно

n8n версії 2.x (потрібна підтримка Data tables).

API-ключ Anthropic з console.anthropic.com: Settings → API keys → Create Key. Підписка Claude Pro чи Max тут не працює — це окремий рахунок, у Billing треба мати кошти.

Крок 1. Імпортувати обидва workflow

У n8n: Overview → Create workflow → меню ⋯ → Import from File. Зробити двічі, для кожного файлу.



Крок 2. Підключити Claude

Credentials → Add credential → Anthropic API.

Вставити свій ключ, дати ім'я, зберегти.

Відкрити workflow «Software inventory → catalog (Claude)», знайти вузол Claude classify і в полі Credential вибрати щойно створені credentials.

Зберегти workflow.

Крок 3. Створити таблиці

Відкрити workflow «Software inventory — setup (run once)».

Натиснути Execute workflow внизу редактора. Відкриється вкладка з формою.

Натиснути в ній Submit.

Вмикати workflow перемикачем Active не треба — це разова дія.



З'явиться «Tables are ready». Створяться sw\_categories, sw\_software, sw\_packages, sw\_runs. Запускати повторно безпечно: наявні дані не затираються.



Крок 4. Увімкнути основний workflow

Увімкнути «Software inventory → catalog (Claude)» перемикачем Active.

У вузлі Form скопіювати Production URL — це робоча адреса форми.

Крок 5. Отримати файл із переліком ПЗ

У PowerShell на потрібному комп'ютері:



winget list > software.txt

Кодування значення не має: розбір розуміє і UTF-8, і UTF-16, і BOM.



Крок 6. Перший прогін

Відкрити адресу форми, завантажити software.txt, натиснути Submit. Для \~130 пакетів це триває кілька хвилин — усе невідоме йде до Claude одним запитом.



На екрані «Готово» буде підсумок і повний розподіл: категорія → продукт → його пакети.



Крок 7. Перевірка, що все працює

Завантажити той самий файл ще раз. У підсумку має бути:



Нових пакетів: 0; оновлених: 0

Нового ПЗ: 0; викликів AI: 0

викликів AI: 0 означає, що довідник працює і другий прогін безкоштовний.



Як це працює далі

Кілька комп'ютерів. Кожен новий файл лише доливає в довідник те, чого там ще немає. Дані попередніх машин не чіпаються. Чим більше файлів, тим менше роботи для AI: спільні програми вже класифіковані.

Довідник не знає, на якій машині що стоїть. Він відповідає на питання «що це за пакет і до якого продукту належить», а не «де встановлено». Поле version — версія з файлу, завантаженого останнім.

Категорії — закритий список із 16 значень. AI не може вигадати нову: схема відповіді технічно це забороняє. Саме тому результати стабільні. Додати категорію можна вручну рядком у sw\_categories.

Ручні правки, які переживають наступні запуски

Що зробити	Де	Результат

match\_method = manual + свій software\_key	sw\_packages	Пакет назавжди закріплений за цим ПЗ

locked = true	sw\_software	AI не перезапише назву й категорію ПЗ

Дописати aliases	sw\_software	Нове правило: пакети з таким префіксом ідуть до цього ПЗ без AI

Формат aliases: id:<початок package\_id> або name:<початок назви>, кілька правил через |, усе малими літерами. Приклад:



id:microsoft.vcredist|name:microsoft visual c++ 20

Що перевіряти, якщо не працює

Симптом	Причина

401 invalid x-api-key у підсумку	Ключ не вставлено або обрано не ті credentials у вузлі Claude classify

Problem loading form	Workflow вимкнений. Увімкнути перемикач Active

Пакети йдуть до AI щоразу	Не створилися таблиці або вони порожні. Запустити setup ще раз через Execute workflow

Мої правки у вузлах зникли	Вкладка редактора n8n була відкрита зі старим станом і перезаписала їх. Перед редагуванням оновлювати сторінку

Скільки коштує

Платить лише перший прогін кожного нового набору ПЗ: один запит до Claude на файл, незалежно від кількості невідомих пакетів (до 150 за раз). Усе, що вже в довіднику, не коштує нічого. Модель — claude-opus-5, замінюється однією константою MODEL у вузлі Match.
